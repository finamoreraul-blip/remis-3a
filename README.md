# remis - Remis Tres Arroyos

App de remis para Tres Arroyos, Buenos Aires.

## Links en vivo

- **App Pasajero:** https://TU-USUARIO.github.io/mi-ruta/pasajero/
- **App Chofer:** https://TU-USUARIO.github.io/mi-ruta/chofer/

## Como funciona

1. El pasajero activa su ubicación con GPS, pone destino y pide un remis.
2. El chofer recibe la alerta en vivo, acepta el viaje y el taxímetro arranca solo con el GPS.
3. Todo conectado en vivo con Supabase.

## Tecnologias

- HTML / CSS / JavaScript
- Leaflet + OpenStreetMap
- Supabase (Base de datos en vivo)
- GitHub Pages (Hosting HTTPS)
